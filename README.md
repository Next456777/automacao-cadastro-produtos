# 🤖 Automação de Cadastro de Produtos com Python

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante um treinamento de Python com o objetivo de automatizar o cadastro de produtos em um sistema web.

A automação utiliza uma base de dados em formato CSV contendo as informações dos produtos e, por meio do Python, realiza o preenchimento dos campos automaticamente no sistema.

O projeto foi desenvolvido como uma forma de praticar conceitos de Python, manipulação de dados e automação de tarefas.

---

## ⚙️ Como funciona

O programa realiza as seguintes etapas:

1. Abre o navegador Microsoft Edge;
2. Acessa o sistema web;
3. Realiza o login;
4. Lê a base de produtos armazenada em um arquivo CSV;
5. Percorre cada produto da tabela;
6. Preenche automaticamente os campos de cadastro;
7. Finaliza o cadastro do produto;
8. Repete o processo até que todos os produtos da base sejam cadastrados.

## 📚 Bibliotecas utilizadas

### PyAutoGUI

Utilizada para automatizar ações no computador, como:

- Abrir programas;
- Digitar textos;
- Pressionar teclas;
- Clicar em posições específicas da tela;
- Realizar ações de forma automatizada.

### Pandas

Utilizada para realizar a leitura e manipulação da base de dados contendo os produtos.
